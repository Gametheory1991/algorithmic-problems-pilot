# History

## 1 November 2026 — Initial release

- The pilot was registered with ten problems. For each problem the question and
  the verification method were recorded before any computation ran. The
  registration text is in PILOT.md.
- Problem 1 (bin packing) was run and verified, and its manuscript, code, and
  result file were published.
- Problems 2 to 10 are published as registrations only. No result is claimed
  for them.

## 2 November 2026 — Problem 2 published

- Problem 2 (sorting networks) was run and verified, and its manuscript, code,
  and result file were published.
- Problems 3 to 10 remain published as registrations only. No result is claimed
  for them.

## 3 November 2026 — Problems 3, 4 and 5 published

- Problem 3 (scheduling) was run and verified, and its manuscript, code, and
  result file were published. Smith's rule was confirmed exhaustively on the
  registered instance sets without release dates, and the smallest
  counterexample with release dates was found in the registered enumeration.
- Problem 4 (travelling salesman) was run and verified, and its manuscript,
  code, and result file were published. Nearest neighbour and 2-opt were
  measured against the published eil51 optimum of 426.
- Problem 5 (optimal stopping) was run and verified, and its manuscript, code,
  and result file were published. The exact dynamic-programming values were
  confirmed against the closed-form threshold formula and a 200,000-trial
  Monte Carlo simulation at each registered n.
- Problems 6 to 10 remain published as registrations only. No result is claimed
  for them.

No results have been corrected or withdrawn.
